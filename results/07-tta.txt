Test-time augmentation: averaging over rotations
================================================

The first change in this round that moves a model number. No retraining and
no new weights: the same network is shown the same photo four times, turned by
a quarter each time, and the four answers are averaged.

The reason it works at all is that a dermatoscope photograph has no top or
bottom, so all four turns are equally fair readings of the same lesion, while
convolution is not rotation invariant and gives four slightly different
answers. Averaging four readings of one thing is steadier than trusting one.

Validation, 1521 images, 293 of them malignant. The test set is not touched
here and still stands at the single measurement in results/05. This decision
does not need it.

Model
-----
ResNet18 fine-tuned for 15 epochs, best epoch 7, weights unchanged. Threshold
0.15, the same rule the app uses. Quarter turns and mirrors are exact
permutations of pixels: no interpolation, no empty corners, nothing invented.

    uv run python -m scripts.measure_tta

Readings averaged
-----------------
    variant                  recall  precision  missed  false alarms  accuracy   PR-AUC  seconds
    no TTA                   93.9%      41.1%      18           394     78.2%    0.721     6.1
    four turns               95.2%      39.4%      14           430     80.5%    0.742     9.5
    four turns + mirror      95.6%      39.8%      13           423     80.3%    0.742    14.6

Four turns is what the app now does.

What the numbers say
--------------------
Fourteen malignant lesions go unnoticed instead of eighteen. On a validation
set of 293 that is four lesions, and it is the number this project exists to
move.

The part that makes it believable is PR-AUC going from 0.721 to 0.742. That
measure does not depend on where the threshold sits, so a rise in it means the
ranking itself got better. Had recall improved while PR-AUC stood still, the
honest reading would have been that nothing improved and the operating point
had merely slid down the same curve.

It is not free. Precision falls from 41.1% to 39.4%, which is 36 more false
alarms out of 1228 benign images. Four fewer missed cancers for 36 more
unnecessary appointments is a trade this project takes deliberately, on the
cost written into config.py: a false alarm costs an appointment, a miss can
cost a life. It is still a trade and not a free lunch.

Per request the cost is smaller than the table suggests. Those seconds cover
1521 images in batches of 32, where four turns really is four times the
arithmetic. A single request is a batch of one against a batch of four, and on
this hardware that is almost the same work: measured against the running
service, /predict went from about 12 ms to 13 ms. The sweep above shows the
cost of measuring; the service barely pays it.

Mirroring was measured and rejected. It adds 0.3 points of recall and leaves
PR-AUC at 0.742, identical to three decimals, so it carries no information the
rotations did not already have. What it does carry is another 54% of inference
time. Rejecting it is the more useful half of this file.

Two things this leaves open, neither of them hidden.

The 0.15 threshold was chosen on predictions made without TTA, so it is no
longer the best point on this curve. A higher threshold would now buy back some
of those false alarms at the same recall. Re-picking it belongs with the
retraining, not here, because doing it now would spend another look at
validation for a number that is about to change anyway.

And the heatmap still explains one orientation. /explain runs Grad-CAM on a
single unrotated pass, because a map built from four averaged gradients
explains nothing in particular.

Which diagnosis it explains, though, now comes from the averaged
probabilities, the same ones the answer is built from. That mattered more than
it looks: reading the class off the single unrotated pass instead disagreed
with the answer on 145 of 1521 validation images, 9.5%, so roughly one caller
in ten would have been shown a heatmap for a diagnosis they were not given.
Before averaging was added the two agreed by construction, and getting that
back cost one line.

What remains is narrower and worth stating: the picture is about the diagnosis
you were told, drawn from one of the four readings that produced it.
